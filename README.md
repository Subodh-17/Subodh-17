## Selected Projects

- **[Marine Pollution Intelligence](https://github.com/Subodh-17/Marine-Pollution-Intelligence-SIH)**
  Satellite oil-slick detection and vessel attribution platform developed for Smart India Hackathon 2026. Segments Sentinel-1 SAR imagery using Lee speckle filtering and adaptive Otsu thresholding, then correlates leeway drift hindcasting with historical AIS trajectories to score candidate vessels.
  *Stack: Python, FastAPI, React, Leaflet, GeoTIFF, SAR Processing*

- **[Predictive Logistics](https://github.com/Subodh-17/Predictive_Logistics_SIH_26251)**
  Forward supply-chain forecasting and route optimization platform for SIH Problem Statement 26251. Produces weather-adjusted statistical demand forecasts, scores delivery priority queues, and optimizes dispatch routes under terrain elevation and weather constraints.
  *Stack: Python, FastAPI, PostgreSQL / PostGIS, SQLAlchemy, React, TypeScript, Docker*

- **[StockVision (Scilab GUI)](https://github.com/Subodh-17/stockvision-scilab-gui)**
  Dedicated desktop numerical studio built in Scilab for time-series forecasting, comparative model evaluation, and backtesting. Evaluates Linear Regression, Autoregressive (AR), and Holt exponential smoothing against naive baselines with expanding-window walk-forward validation and transaction cost modeling. *(Note: Dedicated Scilab GUI implementation, distinct from the Python prototype).*
  *Stack: Scilab (Numerics, Least Squares, GUI Engine, Plotting)*

- **[Blue Carbon MRV](https://github.com/Subodh-17/WCEHackathon2026_Proteas)**
  Measurement, Reporting, and Verification (MRV) platform for coastal blue carbon restoration projects. Pairs mobile ecological field-data collection with a Node.js registry backend and an ERC-20 smart contract for audit-ready carbon credit issuance.
  *Stack: Solidity, Hardhat, Node.js, Express, PostgreSQL, JavaScript*
