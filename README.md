# Subodh
**AI/ML • Open Source • Data • Software Engineering**

I build machine learning systems, data engineering pipelines, and contribute upstream to open-source ecosystems. My work bridges complex backend architectures with applied AI.

## Open Source

- **[Hugging Face Transformers](https://github.com/huggingface/transformers/pull/49192)** *(Open)*
  Fixed `AutoTokenizer` backend selection for CohereLabs `tiny-aya` checkpoints. Implemented regression tests and BPE tokenization regex improvements.
- **[Airbyte](https://github.com/airbytehq/airbyte/pull/87507)** *(Open)*
  Developed `ConfigurablePropertiesFromEndpoint` to enable property history configuration within the HubSpot source connector, expanding declarative CDK capabilities.
- **Corsair** *(Merged, PR #1398)*
  Developed and integrated the Dynapictures plugin.

## Building

- **[Marine Pollution Intelligence](https://github.com/Subodh-17/Marine-Pollution-Intelligence-SIH)**
  Originally developed for the Smart India Hackathon; now an independent prototype. A system leveraging SAR (Synthetic Aperture Radar) and AIS data integration to detect and analyze marine pollution and oil spills.
- **[StockVision](https://github.com/Subodh-17/stockvision-scilab-gui)**
  An interactive forecasting engine utilizing a Regression + LSTM ensemble prediction architecture for financial modeling and backtesting.
- **[Blue Carbon MRV Registry](https://github.com/Subodh-17/WCEHackathon2026_Proteas)**
  Developed during WCE Hackathon 2026. A tokenized carbon-credit registry utilizing an MRV (Measurement, Reporting, and Verification) pipeline. Built with Solidity, IPFS, and an integrated Android field application.
