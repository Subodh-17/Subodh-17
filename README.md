* **[VarshithReddy2006/DevTrack#171](https://github.com/VarshithReddy2006/DevTrack/pull/171)** — `fix(auth): harden Clerk user sync against missing email and race conditions (#115)` (**MERGED**)
  [![TypeScript](https://img.shields.io/badge/TypeScript-3178c6?style=flat-square&logo=typescript&logoColor=white)](https://www.typescriptlang.org)
  [![Prisma](https://img.shields.io/badge/Prisma-2d3748?style=flat-square&logo=prisma&logoColor=white)](https://prisma.io)
  [![PostgreSQL](https://img.shields.io/badge/PostgreSQL-316192?style=flat-square&logo=postgresql&logoColor=white)](https://postgresql.org)
  * *Problem:* In Clerk OAuth authentication webhooks and sync calls, users authenticated solely via phone numbers, usernames, or unverified enterprise SSO had null primary emails. When missing, the service defaulted email to a synthesized string (`${clerkId}@clerk.placeholder`), causing database crashes or silent linking to unintended records. Concurrent webhook arrivals also triggered race conditions on initial user provisioning.
  * *Implementation:* Restructured `ClerkUserSyncService.ts` to enforce atomic Prisma interactive transactions (`$transaction`), explicit null-safety validation, and robust upsert guards. Preserved relational referential integrity across supporting records (profiles, settings, document provisioning) and verified complete resilience across 22 comprehensive unit and integration tests. Merged upstream on 2026-11-11 (Merge SHA: `438c472`).
* **[ThreeMoonsLab/agents-shipgate#1106](https://github.com/ThreeMoonsLab/agents-shipgate/pull/1106)** — `fix(privacy): redact AWS path keys and URL-safe Basic credentials` (**MERGED**)
  [![Python](https://img.shields.io/badge/Python-3776ab?style=flat-square&logo=python&logoColor=white)](https://python.org)
  [![Security](https://img.shields.io/badge/Security-AWS_Redaction-critical?style=flat-square)](https://github.com/ThreeMoonsLab/agents-shipgate)

URL-safe Base64 strings (RFC 4648 with `-` and `_`) or unpadded strings caused false negatives or decoding exceptions in privacy audit logs.
  * *Implementation:* Hardened lookaround assertion boundaries in `src/agents_shipgate/core/privacy.py` to handle directory separators without compromising Shannon entropy heuristics. Implemented RFC 4648 character normalization, safe padding calculations, and `len % 4 == 1` malformed token rejection. Verified across 32 regression tests; merged upstream on 2026-11-06 (Merge SHA: `7607b905`).

  [![ISO 8601](https://img.shields.io/badge/ISO_8601-Config_Hashing-0f172a?style=flat-square)](https://en.wikipedia.org/wiki/ISO_8601)

  * *Implementation:* Designed deterministic scalar canonicalization in `_canonical()` inside `src/agents_shipgate/core/host_grants.py`, enforcing ISO 8601 format while strictly maintaining secret mask order. Rebalanced parallel CI partition durations in `tests/shard_seconds.json`. Verified across 9 unit tests; merged upstream on 2026-11-06 (Merge SHA: `4cd4be7d`).
