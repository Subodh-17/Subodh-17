## About

I build applied machine learning pipelines, geospatial analytics engines, and backend decision-support systems engineered for measurable evaluation and predictable failure modes. My recent work spans deploying memory-bounded ONNX vision inference on satellite imagery, pairing statistical and gradient-boosted forecasting with spatial routing and optimization, and enforcing audit-grade state integrity in automated workflows. Outside of personal systems, I contribute fixes, tests, and reliability improvements across open-source repositories.
