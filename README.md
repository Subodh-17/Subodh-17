## Featured Projects

### [Marine Pollution Intelligence](https://github.com/Subodh-17/Marine-Pollution-Intelligence-SIH)
*End-to-end Sentinel-1 SAR oil spill detection and vessel attribution decision-support prototype.*
- Implements synthetic and real SAR imagery ingestion, Lee speckle filtering, dark-spot geometric characterization, and oceanographic/meteorological leeway drift hindcasting.
- Correlates historical AIS vessel trajectories to calculate explainable, spatio-temporal attribution scores.
- **Technologies:** Python, FastAPI, React, GeoTIFF Processing, Lee Filter, Drift Hindcasting, AIS Correlation.

### [Predictive Logistics](https://github.com/Subodh-17/Predictive_Logistics_SIH_26251)
*Decision-support prototype for predictive logistics and forward supply chain planning.*
- Generates weather-aware consumption forecasts (7/14/30-day horizons) with multi-criteria supply prioritization and terrain-aware route optimization.
- Implements near-real-time inventory tracking via simulated ESP32/RFID sensor telemetry.
- **Technologies:** FastAPI, PostgreSQL, PostGIS, SQLAlchemy, React, Vite, TypeScript, Docker Compose.

### [StockVision](https://github.com/Subodh-17/stockvision-scilab-gui)
*Interactive desktop studio for time-series forecasting, comparative model evaluation, and backtesting.*
- Compares Linear Regression, Autoregressive (AR), and Holt exponential smoothing against a naive last-value baseline on a shared chronological test window.
- Supports expanding-window walk-forward validation and backtests trading signals with explicit transaction costs, slippage, and execution lag.
- **Technologies:** Scilab (Core Numerics, Least Squares, Embedded GUI Controls & Plotting).

### [Blue Carbon MRV](https://github.com/Subodh-17/WCEHackathon2026_Proteas)
*Hackathon prototype for coastal blue carbon restoration measurement, reporting, and verification.*
- Combines full-stack web and mobile reporting interfaces with tamper-evident environmental data verification using smart contracts.
- Implements role-based workflows for project administrators, verifiers, and field workers.
- **Technologies:** Solidity, Hardhat, Node.js, Express, PostgreSQL, HTML5/CSS3, JavaScript.
